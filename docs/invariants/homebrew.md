# Homebrew on a game's board (`profiles/sfight_homebrew.h`)

Part of m2-hle2's load-bearing invariants, indexed in [CLAUDE.md](../../CLAUDE.md): facts reverse-engineered or debugged into the emulator, in no datasheet. Do not re-derive them.

Homebrew ships as a stock set with the program EPROMs swapped (m2-pacman: `sfight` with `epr-19001.15`, `epr-19002.16`, `epr-19021.31` replaced). The game's profile would plant its HLE hooks and interrupt handlers in the homebrew's code, so after a load `profile_adopt_program` reads the program's own interrupt table (ROM word 1 → PRCB → +0x14) and, if it does not name the profile's handlers, runs the set's `any_program` profile instead: no hooks, `irq_vectors`, `board_vblank`. A patched build of the game keeps its table and so its profile. Every profile's slice ends at the board's vblank (HLE Hooks, "Frame pacing"), so `board_vblank` only says the program has no frame hook: the run loop marks the capture's frame and makes the match_replay jump at the vblank instead. A handler still in service after 8 slices is taken to have switched task (m2-sdk's break-in does `flushreg` + `bx`).

- **The sound EPROM is part of the swap.** Homebrew is often run the way MAME takes it: the three files in a folder named `sfight`, the stock zip beside. The sfight profile's loose-file override (`sfight/<file>` in the working directory, `sfight_load`) covers `epr-19021.31` as well as the i960 pair. *Symptom when it did not (Pinboard #1534):* m2-pacman's panel said `NO SOUND` and the game ran silent, because its i960 program pings its own sound program (`0xF0`, answer `0x5A`) and STF's driver from the zip never answers. A zip with all three files swapped always had sound.
- **The comm board is part of STF's board.** MAME's `sfight` has the comm board (`m2comm`, frame offset 0x1C0), so `sfight_homebrew` installs it too (`m2comm_install`, saved with the state) and has a `link_role` hook: m2-megamix's link (`board/src/link.c`) reads its role from a block at backup `0x01D03FF0` ("MMX1", the role, its complement; 1 = MASTER/1P, 2 = SLAVE/2P), which the hook writes before the board boots into its role. Without the board, CN/FG read open bus and the homebrew's link says "no board" (Pinboard #1632, NETPLAY_PROTO_REV 39). Homebrew that never touches `0x01A10000` is unaffected.
