# Following a board one way (`core/follow.h`, issue #228)

Part of m2-hle2's load-bearing invariants, indexed in [CLAUDE.md](../../CLAUDE.md): facts reverse-engineered or debugged into the emulator, in no datasheet. Do not re-derive them.

A leader (the fly's headless board) writes join points and a feed, and followers (the web build's `?follow=`) replay them; only inputs cross. `det_digest --follow` holds every frame check, native and wasm alike (tools/README.md, "Following a board one way").

- **A follower sets the input latch at every slice** (`follow__sub_begin`: `net_held`, `use_net`). The netplay pump's `netplay_release_inputs` clears both whenever there is no session, which is every slice of a follower, so a latch set once at the join was gone by the next slice and the board read the page's keys.
- **Anything the feed cannot carry ends the segment** (`follow_lead_break`): a reset, a state load, a single step, a COP command, SKY EYE, the idle hold. The next slice starts a new join point. A new way for the bridge or host to change the board needs one or the other, or followers split.
- **A web follower plays out of a buffer** (`web_follow_ready`, `main_web.c`; Pinboard #601). It starts or restarts a segment only with `WEB_FOLLOW_PREROLL` (36) frames in hand, or the segment's END, and catches up from past `WEB_FOLLOW_AHEAD` (120) silently, as fast as 10 ms a frame allows. The page polls the feed every 250 ms, so a 20-frame margin ran dry between polls on the fly's feed and the page hitched with garbled sound. A device that cannot gain on the leader (`WEB_FOLLOW_GAIN` in 5 s) gives up the race and plays on behind. A lost WebGL context reloads a follower's page (`m2hle-page.js`): sokol cannot restore one, and the board played on under a black canvas.
- **The board waits only for a stored snapshot** (`emu_state_save_mem`, ~50 ms for 16 MB); a thread deflates it to `seg-N.sta` beside the board (~100 ms more) and only then rewrites `follow.json`, so a follower never reads a half-written state. A follower that reaches END before the next state is out keeps polling the index.
